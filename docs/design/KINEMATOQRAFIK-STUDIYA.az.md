# Bilirsən? · Kinematoqrafik studiya

Qarşılama və ana səhifə mavi projektorlarla işıqlandırılmış studiyaya açılır. Solo hazırlıqda səhnə arxası, dueldə iki podium, rank səhifəsində qızılı kitab nişanı görünür. Profil yarışçı vəsiqəsi kimi qurulub. Tarixçə, hesab formaları və səs ayarları üçün daha sakit səhnə arxası fonu istifadə olunur.

Sual ekranı vaxtı, cari çətinliyi və yarış xalını ayrı göstərir. Pilləkən turun gedişini və açıq sualın xal dəyərini göstərir. Dörd qısa variant uyğun en və şrift ölçüsündə iki sütuna düzülür. Dar ekran və uzun variantlar üçün bir sütun istifadə olunur. Seçimdən sonra cavabların yeri sabit qalır, serverin nəticəsinə uyğun rəng və işarə görünür.

Nəticə ekranında yarış xalı iri rəqəmlə, əvvəlki və cari rank isə eyni sətirdə verilir. Reytinqin dizayn nümunəsində şəxsi yer yuxarıdadır. Qonağın şəxsi rankı tətbiqdə işləyir. Rəsmi sıralama, canlı duel və hesab xidmətləri hazırkı mərhələdə gözləmə və dizayn nümunəsi kimi göstərilir.

Dörd orijinal səhnə materialı telefon üçün sıxılmış JPEG faylları kimi tətbiq paketinə daxildir. Düymələr, vaxt göstəricisi, panellər və mətn cihazda çəkilir. Oyun vəziyyətləri və məzmun mövcud server cavablarından oxunur.

GitHub ekran görüntüləri 390 × 844 ölçüsündə brauzer sınağından çəkilib. Həmin axın 320 və 430 piksel enlərdə də yoxlanılır. Reytinq, hesab və duel nümunələrində sınaq məlumatları istifadə olunur. [Ekran görüntüləri](../images)

TypeScript, ESLint və format yoxlamaları, 28 avtomatik sınaq və 4 brauzer axını keçdi. Brauzer yoxlamalarına canlı solo turu, səs sınağı, uzun mətn və genişləndirilmiş şrift daxildir. iOS, Android və web paketləri ixrac edildi. Expo Go üçün yerli iOS paketi HTTP 200 qaytardı.
